Download the app
  1. Tap Download the app, then open the file when it finishes.
  2. If your phone asks, allow your browser to install unknown apps, then go back.
  3. Tap Install. If Play Protect warns about an unknown app, tap More details, then Install anyway.
  4. Open VGO Rewards from your home screen.

This test app comes straight from VGO, not the Play Store, which is why Android asks first. To update, download it again and install over the old one.
